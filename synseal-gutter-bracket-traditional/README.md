# Synseal Gutter Bracket Traditional

Synseal were a Nottingham based company that used to create conservatory glass roofs.
They closed in 2020 and it has been hard to get spare parts for them - especially the gutter bracket which is prone to breaking.

This project is based off a scan of an existing gutter bracket, and I've created a STL file which you can print on a 3D printer.

The files in this folder are:

- gutter-bracket-synseal-traditional2.xcf - this is a file for Gimp 2.10 where the original scan from a flatbed scanner was cleaned up and separated in to layers.
- gutter-bracket-synseal-traditional-background.png - this is an export of the background layer in Gimp to png
- gutter-bracket-synseal-traditional-background.svg - this SVG is created from Inkscape using the Trace Bitmap feature with about mid range on Speckles, Round corners and Optimize. I exported as SVG format
- gutter-bracket-synseal-traditional-foreground.png - this is an export of the foreround layer in Gimp to png
- gutter-bracket-synseal-traditional-foreground.svg - this SVG is also created from Inkscape using the Trace Bitmap
- synseal-gutter-traditional-svg.FCStd - this is a FreeCAD drawing where I imported the 2 SVG files, extruded the shapes to the right thickness and fused the parts together.
- synseal-gutter-traditional.stl - this is an export from FreeCAD in the sliced format for 3D printing
